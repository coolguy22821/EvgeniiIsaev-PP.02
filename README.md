# Регистрация на студенческий конкурс + уведомления старост в MAX

Первая учебная версия проекта (Неделя 1).

## Назначение
Веб-приложение позволяет студенту оставить заявку на конкурс. Данные сохраняются
в SQLite. После сохранения вызывается отдельный адаптер уведомлений для старост.
На текущем этапе адаптер работает в демонстрационном режиме и выводит сообщение
в консоль; реальная отправка через MAX API ещё не подключена.

## Функции первой версии
- форма регистрации участника;
- проверка обязательных полей и базовая проверка email;
- сохранение заявок в SQLite;
- просмотр списка заявок;
- вызов отдельного модуля уведомлений (демо-заглушка).

## Запуск
Требуется Python 3.10+.

```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
python app.py
```

Откройте в браузере `http://127.0.0.1:5000`.

## Тестирование
```bash
python -m unittest discover -s tests -v
```

идентификаторы чатов в публичном репозитории. Для реальной эксплуатации нужны
согласование обработки персональных данных и проверка официальной документации MAX.
